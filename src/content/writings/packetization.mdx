A JSON body is not what the fibre sees. Encapsulation wraps the same intention in headers until it becomes segments, packets, frames.

HTTP produces bytes. TCP (or QUIC) cuts a stream, numbers it, and argues about loss. IP finds a network. The physical layer is light or voltage.

HTTP/2 and HTTP/3 split streams so one slow request does not stall its neighbours — head-of-line blocking as a design enemy, not a trivia answer.
